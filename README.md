# Impacto Visual

## Descripcion
Impacto Visual es un proyecto enfocado en la produccion multimedia, edicion de video digital y diseno de movimiento, creado para apoyar emprendimientos locales y proyectos escolares mediante la creacion de contenido visual de impacto.

## Objetivo
Desarrollar piezas audiovisuales y soluciones narrativas digitales aplicando tecnicas avanzadas de montaje, edicion y diseno grafico.

## Autor
Camilo Esteban Abella Perez

## Estado actual del proyecto
En fase de planificacion y estructuracion de contenidos audiovisual y diseno de prototipos iniciales.
